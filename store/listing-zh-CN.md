## 三、详细说明（Detailed description，≤ 16000 字符）

```
【一句话介绍】
视频嗅探下载器会观察你当前网页正在加载的视频资源，把它们整理成一份清晰列表——你只需要点一下「下载」。

【它解决什么问题】
很多网页视频并不是一个可以直接保存的文件：它们被切成成百上千个分片（m3u8 / m4s / ts），或者以 blob: 形式交给播放器播放，右键「另存为」根本拿不到文件。
更麻烦的是，B站、抖音这类站点把**画面和声音拆成两条独立的流**分别传输，直接下载只能得到"有画面没声音"和"有声音没画面"两个文件。
本扩展把这件事变简单：播放页面中的视频，列表里就会出现真实的流地址，选好清晰度，点下载，剩下的分片抓取、解密、音视频合并交给它。

【核心功能】
• 三重互补的发现通道：① 实时监听网络请求；② 打开扩展或点重新扫描时，回溯浏览器的资源时间线，把「扩展开始观测之前」就已发出的媒体请求补报回来；③ 扫描页面 <video> 元素。三条互为补充，尽量减少漏检。
• 内容签名识别：有些站点把 m3u8 以 text/plain 返回、地址又完全不带后缀，只看后缀和响应头必然漏掉。扩展会拉取响应开头几 KB，按内容特征（#EXTM3U / MPD / ftyp / TS 同步字节）判定真实类型；确认不是媒体的条目会被自动剔除，不会污染列表。
• 格式覆盖：HLS（.m3u8，含 master 清晰度列表与独立音频组）、DASH（.mpd 清单解析）、MP4、WebM、FLV、MKV、fMP4（.m4s）、TS 分片统一识别并分类标注。
• 音视频轨自动合并（B站、抖音、YouTube 等分离传输的站点）：自动判断每条轨是视频轨还是音频轨，把同一视频的两条轨按解码时间合成为**一个**含画面与声音的文件——不会只给你"没声音的画面"，也无需 ffmpeg 等外部工具。覆盖多种形态：`.m4s` 整轨、无后缀的 `video/mp4` + `audio/mp4` 分离流、YouTube 式同路径 `&mime=` 声明轨（连被 `&range=` 切碎的请求也会自动归并成一条）、HLS 的 `#EXT-X-MEDIA` 独立音频组、DASH 清单里的音视频 Representation，以及 VP9/Opus 的 WebM 轨（合并后仍为 `.webm`，不会错标成 `.mp4`）。想只留画面时也可选择「仅视频」；万一合并失败，视频轨与音频会分别保存，不丢数据。
• DASH 清单直接读透：点「选择清晰度」即可看到清单里的画面档位（分辨率 / 编码 / 码率 / 分片数），不用等播放器把分片都请求一遍；清单里若有独立音频轨，下载时自动一并取回并合并。
• 清晰度任选：自动解析 master 播放列表（HLS）与 MPD 清单（DASH），按分辨率/码率降序列出全部档位（最高可到 4K 档位）。
• 自动合并与转封装：分片并行下载后在本地合并；使用内置的 mux.js 在浏览器内把 TS 转封装为标准 MP4，无需安装 ffmpeg；转封装失败会自动回退为可直接播放的 TS 文件。
• AES-128 加密流支持：对使用 #EXT-X-KEY 的加密 HLS 流，在本机完成密钥获取与解密。
• 防盗链自动重试：部分站点会校验请求来源，若常规下载被拒绝，扩展会自动改用带来源信息的通道重试同一文件。
• 实时进度：分片进度、已下载体积、实时速度一目了然；支持取消任务；关闭弹窗后下载仍在后台继续。
• 一键复制：把任意资源的真实流地址复制到剪贴板，便于交给 yt-dlp、ffmpeg 等工具继续处理。
• 活的播放列表：识别直播流（#EXT-X-ENDLIST 缺失）并提示只能保存当前已缓存的片段。
• 简洁界面：按 HLS / 视频文件 / 分片 / 页面元素分类筛选，一眼看清页面里到底有什么。

【隐私与安全（重要）】
• 零服务器、零账号：本扩展没有后端。解析、解密、合并全部在你的电脑上完成，不上传任何浏览记录、下载记录或视频内容。
• 无统计、无广告、无追踪：扩展内不含任何分析 SDK，不做行为上报。
• 明确的技术边界：本扩展不破解 DRM（如 Widevine / PlayReady / FairPlay）加密内容，遇到这类内容会直接失败——这是设计上的限制，请勿尝试规避。
• 使用政策：扩展内置《使用政策与免责声明》与《隐私政策》，点击界面右下角的链接即可查看。

【权限说明】
• 读取你的数据（webRequest）：以只读方式观测页面发起的网络请求，用于识别视频地址。不修改、不阻断任何请求。
• 下载文件（downloads）：把你点击下载的资源保存到本机。
• 其他权限（declarativeNetRequest / storage / tabs / offscreen）：分别用于补齐来源请求头、保存你的设置、归类嗅探结果、以及在本机完成分片合并与写出。详见隐私政策。

【如何使用】
1. 打开包含视频的网页并开始播放。
2. 点击工具栏中的扩展图标，等待列表出现资源（也可点右上角 ⟳ 重新扫描）。
3. HLS 资源点「选择清晰度」挑选画质；列表里出现「M4S·视频」时点「下载（含声音）」，会直接得到含画面与声音的单个 MP4；其他资源直接点「下载」。
4. 进度显示在「下载任务」区，文件保存在浏览器下载目录（可在设置中指定子目录）。

【适合谁用】
• 需要保存自己上传的素材、自有课程内容的自媒体与运营同学。
• 需要离线观看已获授权内容的学习者。
• 需要调试自家站点媒体资源的开发者与测试人员。
• 需要把公开课、CC 授权视频存档备查的研究者。

【不适合做什么（如实说明）】
• 不支持、也不会支持破解 DRM 加密的付费内容。
• 部分站点使用短时效签名、令牌或强制 Referer 校验保护资源，可能造成下载失败；这是站点的正当技术措施，扩展不会尝试规避。
• 直播流只能保存开始下载那一刻已缓存的分片，它不是录制工具。
• 浏览器内置页面（chrome://、扩展商店页面）无法嗅探，这是浏览器限制。

【合规提示】
请仅下载你本人拥有版权、已获得权利人授权，或目标网站明确允许下载的内容。使用者需自行确保其下载行为符合当地法律法规与目标网站的服务条款。开发者不对使用者下载内容的合法性作出任何保证，也不承担由此产生的责任。
```

## 五、隐私实践选项卡（Privacy practices）—— 逐字段填写答案

### 5.1 单一用途说明（Single purpose description）

```
识别当前网页正在播放或加载的视频资源（如 HLS/m3u8、MP4、DASH 等流媒体），并把用户有权保存的内容下载到本机。除此之外不做任何其他事情——它不是下载管理器，也不处理非视频类文件。
```

### 5.2 各权限的用途说明（Permission justification）

**读取你的数据（webRequest）**

```
以只读方式观测页面自身发起的网络请求，从中识别视频流地址（.m3u8 / .mpd / .m4s / .ts / .mp4 等）并确定其类型。扩展不会修改、阻断或伪造任何请求，也不会把请求内容发送到外部。
```

**读取你的浏览活动（tabs）**

```
需要获取当前标签页的 ID 与标题：ID 用于把嗅探到的媒体资源归属到正确的标签页（多标签页同时播放时不会串台），标题用于生成默认的下载文件名。不读取浏览历史，不做任何行为分析。
```

**管理你的下载内容（downloads）**

```
当用户点击界面上的「下载」按钮时，把已识别的视频资源保存到本机下载目录，并在界面上显示该下载任务的进度与结果。
```

**存储（storage）**

```
在本机保存三项用户设置（保存子目录、输出格式、分片并发数）以及当前标签页的临时嗅探结果。嗅探结果存于会话存储，标签页关闭即清除。
```

**declarativeNetRequest**

```
为扩展自身发起的视频分片请求补充来源（Referer）请求头，使部分校验请求来源的站点资源能够正常访问与下载。仅使用会话级（session-scoped）规则，不对用户的其他浏览请求设置任何拦截或改写规则。
```

**offscreen**

```
Manifest V3 的后台服务工作线程不具备 DOM 与 Blob 能力。扩展需要借助离屏文档完成分片二进制数据的接收、AES-128 解密、TS→MP4 转封装、视频轨与音频轨的合成，以及最终文件写出。离屏文档与扩展同源，不加载任何远程代码。
```

**网站访问权限（host permissions，所有网站）**

```
视频资源可能由任意域名提供，且不同站点使用不同的 CDN。扩展需要在用户访问的任意页面上监听媒体请求（识别视频地址），并在用户点击下载时访问对应的资源域名以取回文件。该权限仅用于视频资源的识别与下载，扩展不会读取、分析或上传页面内容。
```

### 5.3 是否使用了远程代码（Remote code）

```
否（No）。所有可执行 JavaScript 均随扩展一同打包分发，包含本地化的开源库 mux.js（用于 MP4 转封装）。扩展不从网络获取或执行任何脚本，也不使用 eval()。
```

### 5.4 数据使用（Data usage）—— 勾选项

**勾选以下类别：**

- ✅ **网站内容（Website content）**

  理由：扩展会在本机读取页面中的媒体资源地址与相关请求 URL（属于"网站内容"范畴），用途仅为识别视频资源并完成下载。数据不离开用户设备。

**以下类别全部不勾选：**

- ⬜ 个人身份信息（Personally identifiable information）
- ⬜ 健康信息（Health information）

- ⬜ 个人通信（Personal communications）
- ⬜ 位置（Location）
- ⬜ 网络历史记录（Web history）
- ⬜ 用户活动（User activity）

**三项认证（必须全部勾选）：**

- ✅ 我不会将用户数据出售或转让给第三方（除经批准的使用情形外）
- ✅ 我不会将用户数据用于与单一用途无关的用途
- ✅ 我不会将用户数据用于确定信用度或用于放贷目的
